# Pinned MR UDS / Manager distribution

Read-only copy of the 46 original Manager SVGs, their original catalog and visual tokens from [MR-Studio PR #276](https://github.com/vladleng/MR-Studio/pull/276), commit `f0c3a67d2c67d1d9ff863bccc01eb11fb9e6cdb5`.

The canonical editable library remains `vladleng/MR-Studio/assets/ui/mr-uds/`. This repository packages a Manager-only subset at the same relative paths; its `manifest.json` intentionally lists only those 46 assets. This is distribution, not an independently edited theme/art fork. Source and license notes are preserved in each original catalog entry: original MR artwork, same license as the upstream project. No third-party artwork/fonts added.

`UPSTREAM.json` pins every original SVG/catalog/token file by SHA-256. To update, review a new upstream commit, replace these originals and their provenance together, and regenerate `src/MRManagerAssets.h` with `python tools/embed_mr_manager_assets.py`. Do not run upstream `build_kit.py`, edit generated C++, or redraw these SVGs locally.

Only the eleven catalog entries marked `icon` are embedded in the executable; the host paints actual names/status/priority/progress. The 25 `reference` examples and ten `template` sources remain catalog/reference resources, never replacement user data. Embedding is offline and deterministic. SVG parsing is once at TaskTree construction on the UI thread, never during row paint or an audio callback. No network or runtime filesystem reads are needed.

Validation: `python tools/embed_mr_manager_assets.py --check` verifies provenance, source SVG structure, catalog IDs and generated bytes. Runtime image geometry, data bindings, gestures and persistence are unchanged by this cosmetic adoption.
