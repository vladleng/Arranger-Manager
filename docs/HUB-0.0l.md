# Arranger Manager 0.0l — Windows application

The ZIP contains a portable `Arranger Manager.exe`. Extract the folder, then run the executable; Studio Pro and a VST3 installation are not needed to view a saved project.

1. Click **Open .song** and select a saved Studio Pro project.
2. Expand the project and tracks to see sections, clip types, statuses, notes, track colors and markers.
3. Save the project in Studio Pro when you want the application to pick up changes. While running, it checks the selected file and refreshes after it changes; **Refresh** is also available.

The application remembers the last selected project on this computer. This initial Windows version opens one project at a time and reads it without modifying the `.song`. Unsaved changes in Studio Pro are not visible. A catalog of multiple projects and editing closed projects are future stages.

The earlier VST3 Hub remains available for in-DAW use; this package is the standalone application only.
