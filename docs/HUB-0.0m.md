# Arranger Manager 0.0m — song catalog

Extract the ZIP and run `Arranger Manager.exe`. No VST3 installation is required.

- Click **Add .song** to import one or several saved Studio Pro projects. The app remembers the list between launches.
- Click **New folder** to create a group. Select a folder before importing to place new songs there. Right-click any song and choose **Move to…** to regroup an existing entry. Right-click a folder to remove it; its songs return to **Songs**. Removing a song from the catalog never deletes its `.song` file.
- Expand a song to show its tracks and clips. Click its row to select its Info and Notes in the header. Save edits in Studio Pro to refresh a project in the catalog; the app remains read-only.
- **PROG** follows Status. It shows completed tagged clips over all tagged clips and a proportional green bar for folders, songs and tracks. Untagged clips are not counted. Status is reserved for individual clip labels.

The catalog stores paths to `.song` files on this computer. Missing files remain visible in the list with an error so they can be removed or found again. This version does not edit closed projects.
