# Arranger Manager 0.1 fix2 — Windows app

Распакуйте ZIP и запустите `Arranger Manager.exe`. VST3 устанавливать не нужно.

- `Add .song` добавляет сохранённые проекты Studio Pro, `New folder` создаёт группу. Правой кнопкой на песне можно переместить её в другую папку или убрать из каталога; исходный `.song` не удаляется.
- Дерево: **папка → песня → трек → клип**. Треки раскрываются по нажатию; группа Markers и сами маркеры в дереве не показываются. Секции Arranger по-прежнему обозначаются у пересекающихся клипов.
- Статус песни задаётся в её ячейке Status и хранится в локальном каталоге приложения. Он не зависит от статусов треков.
- **Статус трека** задаётся в Studio Pro в начале **имени трека**: `WIP | Drums`, `DONE | Bass` и т. п. После сохранения `.song` приложение показывает `Drums`/`Bass` в названии, статус — в колонке Status. Имя без распознанного статуса скрывает трек вместе с его клипами. Статус из старой первой строки Track Notes больше не используется. Заметка трека полностью видна в Notes.
- **PROG песни:** `треки DONE / все треки с распознанным статусом`. Например, два DONE и один WIP дают `2/3`, независимо от клипов. Неотмеченные треки скрыты и не входят в расчёт.
- **PROG трека:** `клипы DONE / все клипы с распознанным статусом` на этом треке. Клип без статуса не участвует. **PROG папки:** `песни DONE / все песни в папке` по ручным статусам песен. Пустой знаменатель показывается как `-`.

При переходе с 0.1 fix1 перенесите статус из заметки в начало имени каждого нужного трека в Studio Pro и сохраните проект. Сам текст заметки можете оставить: приложение больше не читает из него статус. Каталог и ручные статусы песен сохраняются. Приложение читает только последнее сохранённое состояние `.song` и не записывает в проект.
