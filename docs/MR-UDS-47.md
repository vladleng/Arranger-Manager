# #47 — MR UDS Manager, косметический срез

Кандидат на базе непринятой 0.1h / PR #46, source `fa92f6dcf2d8c514715cb8e663412646ffe8ddd5`. Тематическая ветка `ui-47-mr-uds`; в main не слито. Это обновление оформления Manager, не MR Live integration #48 и не удаление legacy #7.

## Внедрено

- Manager-профиль MR UDS: фон `#191A1C`, панели `#242629`, поля/строки `#292D33`, выбранное `#2B3037`, контуры `#415167`, текст `#DAE5F4`, metadata/focus `#91BBEE`, progress `#59AD87`.
- Одна LookAndFeel для оболочки Manager, полей/табуляции/кнопок, scrollbars и контекстных меню. Текстовые кнопки плоские с тонким контуром; empty-label icon buttons без постоянной рамки. Legacy Hub сохраняет свой прежний LookAndFeel.
- Status pills, P1–P4, полосы progress, имена, Notes, выбранные строки/иерархия/архив и редактор блоков используют тот же профиль. Текст маленьких badges осветлён для контраста на исходных P1–P4 фонах.
- Реальные статусы/приоритеты/проценты рисуются из прежней модели. Пять status glyphs и organizer icon взяты из MR Manager Kit, не emoji. POOL и DRAFT остаются отдельными подписанными статусами с native outline marker; BLOCKED использует собственный SVG.
- Видимые размеры строк/колонок, hit areas, focus, клавиатурные действия, раскрытие/ПКМ, свойства/автосохранение/Undo, ID и archive commands не изменялись. Checkpoint checkbox отражает DONE; иллюстративный checklist не выдаётся за завершение задачи.

## Доставка ассетов

`assets/ui/mr-uds/` — read-only Manager-only distribution канонической библиотеки из MR-Studio commit `f0c3a67d2c67d1d9ff863bccc01eb11fb9e6cdb5`, PR MR-Studio#276. Все 46 SVG, исходные catalog/tokens сохранены без изменения содержимого; SHA-256 и source/license — в UPSTREAM.json/catalog. Manifest содержит только этот поднабор, сохраняя semantic IDs и относительные пути.

Offline generator `tools/embed_mr_manager_assets.py` формирует `src/MRManagerAssets.h`: палитра из manager.json и одиннадцать icon-ресурсов. Reference/template SVG не становятся фиктивными именами/значениями в UI. Подготовленные Drawables создаются один раз при создании TaskTree на UI thread; paint не читает диск/сеть и не парсит SVG. Пакет работает без папки ресурсов рядом с EXE.

Обновления идут из канонической MR Studio библиотеки с новой закреплённой ревизией. Редактировать локальные SVG или запускать старый build_kit.py нельзя; это не второй независимо развиваемый kit.

## Проверки и границы

Проверены diff/источники, whitelist затронутых файлов, структура/происхождение SVG, ссылки каталога и точное соответствие generated header (`python tools/embed_mr_manager_assets.py --check`). Схема/хранилище/model/commands/queries/sessions, CMake и зависимости не изменены.

Для этого визуального среза выполняется только адресная Windows Desktop сборка и пакетирование. CI отдельной ветки ограничен whitelist; существующая полная Windows CI сохранена для остальных веток. Полный CTest, Hub/VST3 сборка, GUI smoke, screenshots/preview и DPI matrix автоматически не запускаются по правилу косметических изменений MR UDS. Они не заявляются пройденными. Нативную визуальную приёмку выполняет пользователь. Ранее пройденные восемь наборов 0.1h не являются новым тестированием #47.

## Проверка пользователем

Открыть обычную страницу → Задачи: проверить новые статусы/P1–P4/progress, раскрытие задачи и Notes чек-поинта, меню ПКМ. Затем открыть полный экран задачи, редактирование блоков и Архив. Проверить читаемость текста, выделения и фокуса на своём масштабе Windows. Приёмка #47 и приёмка/merge 0.1h остаются отдельными действиями.
