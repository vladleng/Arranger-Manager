# Arranger Manager 0.1 fix3 — Windows app

Распакуйте ZIP и запустите `Arranger Manager.exe`. VST3 устанавливать не нужно.

- Дерево: папка → песня → трек → клип. Статус песни задаётся в приложении, статус трека — в его имени в Studio Pro (`WIP | Drums`), статус клипа — в имени клипа (`WIP | Guitar take`). Трек без статуса не показывается.
- Слева в строке клипа показано его имя без префикса статуса. Type содержит значок аудио/MIDI. Следующая колонка **Parts** показывает цветные квадраты секций Arranger, которые пересекают клип. Если квадраты не помещаются, появляется `+N` для оставшихся секций. Отдельной колонки Position больше нет.
- **Notes клипа** заполняется из маркеров Studio Pro. Назовите маркер `mk1 | текст` или `mk1 текст`. Если нужно несколько заметок на одном клипе, используйте `mk1`, `mk2` и т. д. В колонке будут `mk1: текст · mk2: текст` в порядке позиций маркеров. Обычные маркеры без префикса `mk` игнорируются. Маркер относится к каждому клипу, над которым он находится: позиция маркера от начала клипа включительно до его конца не включительно. На границе двух последовательных клипов он относится к следующему.
- PROG трека считает размеченные клипы, PROG песни — отмеченные статусом треки, PROG папки — песни с ручным статусом DONE.

Сохраняйте `.song` в Studio Pro после изменения имён клипов, маркеров и треков. Приложение читает последнюю сохранённую версию и не изменяет файл проекта.
