# 0.1b — задачи песни и чек-поинты

Эта итерация построена непосредственно на принятой 0.1 fix4. Она не содержит инструмента записи копии из закрытого PR #28. Studio Pro `.song` остаётся источником дорожек, клипов и метаданных; приложение читает только последний сохранённый снимок.

## Работа в приложении

1. Добавьте `.song`, раскройте песню. Нажмите правой кнопкой по песне и выберите **New task...**. Назовите задачу, например «Композиция».
2. Нажмите правой кнопкой по задаче: **New checkpoint...** для «Куплет» и «Припев», **Rename...** для нового названия, **Delete task...** для удаления задачи вместе с чек-поинтами после подтверждения.
3. Нажмите правой кнопкой по чек-поинту для Rename или Delete. Кликните по полю Status задачи или чек-поинта, чтобы выбрать POOL, TODO, WIP, DRAFT, WAIT, DONE или BLOCKED. Новые элементы получают TODO.
4. Задача с чек-поинтами показывает PROG `DONE / всего`. PROG песни считает размеченные треки и задачи верхнего уровня; только статус DONE увеличивает числитель. Чек-поинты не дают второго вклада в песню, а завершение всех чек-поинтов само по себе не переключает статус задачи в DONE.

Задачи и статусы хранятся в локальном каталоге приложения по пути песни. Перезапуск сохраняет их; удаление песни из каталога удаляет задачи, исходный `.song` остаётся на месте. Для переноса на другой компьютер пока нет штатного экспорта каталога. В VST3 Hub локальные задачи каталога не показываются.

## Проверка

Создайте «Композиция» с «Куплет» и «Припев», отметьте один чек-поинт DONE: задача показывает 1/2. Песня с двумя размеченными треками, один из которых DONE, и этой одной задачей TODO показывает 1/3. Установка статуса задачи DONE даёт 2/3, независимо от незавершённого чек-поинта. После перезапуска названия и статусы сохраняются. Перепроверьте, что `.song` не изменился и клипы по-прежнему ограничены Start/End.
