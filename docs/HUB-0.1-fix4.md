# Arranger Manager 0.1 fix4 — Windows app

Распакуйте ZIP и запустите `Arranger Manager.exe`. VST3 устанавливать не нужно.

- Дерево: папка → песня → трек → клип. Статус песни задаётся в приложении, статус трека — в начале имени дорожки Studio Pro (`WIP | Drums`). Трек без статуса скрыт.
- Имя клипа задаётся в Studio Pro по схеме `STATUS | название | заметка`, например `WIP | Гитара | Переписать вступление`. Название выводится слева, статус в Status, текст после второго `|` — в Notes. Заметка необязательна. Для заметки с символом `|` всё после второго разделителя остаётся в Notes.
- В приложении видны только аудио и MIDI клипы, **целиком находящиеся** в диапазоне от маркера `Start` до маркера `End` (конец клипа может совпадать с `End`). Клипы вне диапазона, в том числе расположенные за `End` в Scratch Pad, не учитываются в PROG. При отсутствующих, дублирующихся или неправильно расположенных Start/End клипы скрываются и выводится предупреждение.
- Маркеры `mkN` больше не дают заметок и не отображаются в дереве. Они остаются в Studio Pro для своих задач. Остальные маркеры также не используются для Notes.
- Type показывает аудио/MIDI, Parts — цветные квадраты пересекающихся секций Arranger. Отдельной колонки Position нет.
- PROG трека считает клипы с распознанным статусом внутри диапазона песни; PROG песни считает отмеченные статусом треки; PROG папки — песни с ручным статусом DONE.

После изменения имён клипов, треков или границ Start/End сохраните `.song` в Studio Pro. Приложение читает последнюю сохранённую версию и не изменяет файл проекта.
