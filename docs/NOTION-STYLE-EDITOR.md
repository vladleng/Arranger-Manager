# Страницы и задачи: прямой ввод вместо технических форм

Уточнение пользователя после #47: непонятная вкладка «Блоки», крупные значки и отсутствие ввода по двойному клику в «Заметок пока нет». Этот срез изменяет геометрию и поведение, поэтому прежнее исключение «только косметика» к нему не применяется.

## Изученные Notion сценарии

Проверены официальные [Writing and editing basics](https://www.notion.com/help/writing-and-editing-basics), [Sub-items](https://www.notion.com/help/tasks-and-dependencies) и [Table view](https://www.notion.com/help/tables): страница с непосредственным вводом, типы содержимого через `/`/меню блока, строки таблицы и подзадачи в раскрывающейся иерархии. Это ориентир взаимодействия существующего объёма Manager, не заявление полной функциональной совместимости с Notion.

## Страница

«Содержимое» — описание и материалы выбранной страницы; «Задачи» — её задачи. Вместо списка блоков слева и технической формы справа содержимое теперь редактируется прямо в документе. Название блока, тип и отдельное большое поле больше не занимают экран.

- Клик в текст — ввод. Enter добавляет следующий абзац; Shift+Enter — перенос внутри текущего.
- `/` открывает выбор пяти существующих типов: текст, заголовок, список, чек-лист и ссылка. Меню `⋮⋮` также меняет тип, дублирует, перемещает, удаляет, открывает настройки URL и явное перечитывание с подтверждением.
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y — история только данного документа; Ctrl+S — сохранить. Сохранение текста автоматически после паузы и перед навигацией.
- Старые name-only заголовки отображаются своим прежним текстом, не исчезают. Редактирование и порядок сохраняют ID, URL и checked; текстовый чек-лист не завершает родительскую задачу автоматически.
- Ошибка записи оставляет черновик и блокирует переход; перечитывание требует подтверждения.

## Таблица

- Высота строки 32 вместо 44 px; значки 9–12 вместо 16–18, status pill 20 px. Сетка проще, больше места для названий.
- Двойной клик по названию — ввод в ячейке. Значок страницы/меню «Открыть» открывает подробную запись. Клик по статусу/приоритету — значения; checkbox подзадачи — DONE/TODO.
- Двойной клик по «Заметок пока нет» или заметке — многострочный ввод здесь же, без перехода на другой экран. Ctrl+Enter или выход из ячейки сохраняет; Esc отменяет. Перед переходом/закрытием читается фактический ввод, даже до TextEditor notification.
- Под раскрытой задачей есть строка «+ Новая подзадача». Клик активирует название; Enter создаёт одну запись с новым ID, Esc отменяет, пустая строка ничего не создаёт. Notes не преобразуются в задачу молча.
- Прямой ввод работает также для сохранённых локальных задач старого каталога без открытия/записи `.song`. Это доступ к своим данным, не новая интеграция Studio Pro.
- Подзадачи используют существующие checkpoint records и один уровень владения задачей; произвольную новую многоуровневую схему эта итерация не вводит. Схема workspace, источники и правила прогресса не меняются.
