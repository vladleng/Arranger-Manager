# Arranger Manager 0.1 fix1 — Windows app

Распакуйте ZIP и запустите `Arranger Manager.exe`. VST3 устанавливать не нужно.

- **Добавление и обзор.** `Add .song` добавляет сохранённые проекты Studio Pro, `New folder` создаёт группу. Правой кнопкой на песне можно переместить её в другую папку или убрать из каталога; исходный `.song` не удаляется. Группы Tracks/Markers и треки раскрываются по запросу.
- **Статус песни.** Нажмите на её ячейку Status и выберите POOL, TODO, WIP, DRAFT, WAIT, DONE, BLOCKED либо Clear status. Статус песни хранится в каталоге приложения на этом компьютере, не в `.song`.
- **Статус трека.** В Studio Pro откройте заметки нужного трека и запишите в **первой строке** `WIP`, `WAIT`, `DONE` или другой статус из списка выше. Можно добавить текст через `|`, например `WIP | Дописать гитару`, либо с новой строки. После сохранения проекта Hub покажет статус в Status, а остальной текст в Notes. **Трек без статуса в первой строке не показывается в Hub и не участвует в PROG песни.** Статус трека в приложении теперь не редактируется.
- **PROG трека/песни.** `DONE / все клипы с распознанным статусом`. Обычные аудио- и MIDI-клипы без статуса исключены из обоих чисел. На уровне песни учитываются только треки со статусом в заметке. Пустой знаменатель показывается как `-`.
- **PROG папки.** `число песен со статусом DONE / все песни в папке`. Песни без статуса и с любым другим статусом считаются незавершёнными. PROG папки не зависит от количества клипов внутри песен.

Клипы и заметки редактируются в Studio Pro. Hub обновляет состояние после сохранения `.song`, не изменяя проект. При переходе с первой версии 0.1 локально сохранённые статусы треков больше не используются: чтобы сохранить их, перенесите нужные статусы в заметки соответствующих треков Studio Pro и сохраните проект. Статусы песен и каталог сохраняются.
