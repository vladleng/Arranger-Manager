# 0.1b fix1 — локальные заметки и компактный список

Построено на проверенной пользователем 0.1b, которая основана на 0.1 fix4. Файл `.song` приложение только читает.

- Кружки задач и треков стоят на одной вертикальной линии; задача без чек-поинтов сохраняет отступ. У чек-поинта слева небольшая точка.
- В Type только иконки: задача, чек-поинт, аудио и MIDI. Текст Music/Task/Check скрыт.
- Щёлкните в Notes строки задачи, чек-поинта, трека или клипа либо откройте контекстное меню **Edit local note...**. Введите заметку и нажмите Save. Пустой текст удаляет локальную заметку. Перезапуск приложения сохраняет записи в каталоге.
- Нативные заметки треков и часть имени клипа после `|` не выводятся в Notes строк. Метаданные Info и Notes **самой песни** по-прежнему показываются в шапке из `.song`. Изменение локальных заметок не меняет Studio Pro проект.

Заметки задач и чек-поинтов связаны с их ID; заметка трека — с trackID. Заметка клипа связана с дорожкой, типом, clipID, стартом, длиной и форматом времени. Повторяющийся clipID дополняется этими атрибутами и порядковым номером совпадения. Переименование клипа сохраняет привязку; перенос или изменение длины могут отсоединить прежнюю заметку. Если Studio Pro создаст несколько полностью совпадающих клипов и изменит их порядок, заметки могут поменяться местами. Локальные заметки относятся к пути песни в каталоге; удаление песни из каталога удаляет их.

## Проверка в Windows

Создайте задачу без чек-поинтов рядом с задачей со спойлером и треком: серые кружки задач и кружок трека должны стоять на одной вертикали. Проверьте точку чек-поинта и отсутствие слов в Type. Введите по заметке каждому из четырёх видов строк, сохраните, перезапустите приложение и проверьте содержимое. Очистите одну заметку и убедитесь, что она исчезла. В шапке должны остаться Info и Notes песни; файл `.song` не должен измениться.
