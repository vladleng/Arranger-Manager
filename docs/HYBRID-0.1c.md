# Arranger Manager 0.1c — редактирование в таблице

Основа — 0.1b fix1; эта версия дополняет её функции. Проект Studio Pro (`.song`) приложение только читает. Задачи, чек-поинты, локальные заметки и тип песни хранятся в каталоге приложения.

## Работа со списком

- Щёлкните в Notes задачи, чек-поинта, трека или клипа и печатайте в самой ячейке. Enter добавляет новую строку; переход в другое поле сохраняет заметку, Esc отменяет правку. Пустая заметка удаляется. Контекстное меню сохраняет большой редактор как запасной способ.
- Дважды щёлкните по названию задачи или чек-поинта, чтобы переименовать его в строке. Enter или выход из поля сохраняет имя, Esc отменяет. Пустое имя не сохраняется.
- Перетащите задачу на другую задачу той же песни или чек-поинт на другой чек-поинт той же задачи. Голубая линия показывает положение перед/после цели. Порядок сохраняется между запусками вместе со статусами и заметками. Перемещение между песнями и задачами не предусмотрено.
- В колонке Type песни щёлкните по значку и выберите **Beginning** (красный круг), **Rough sketch** (жёлтая рыбка), **Mixing** (синий микшер) или **Final mix** (зелёный Play в круге). **Clear type** снимает выбор. Для песни без типа показан серый контур круга. Тип не меняет ручной Status или PROG.

В Type по-прежнему только значки, без подписей; слова используются лишь в меню выбора. Info и Notes самой песни остаются в шапке из сохранённого `.song`. Нативные заметки дорожек и третья часть имени клипа не заполняют локальную колонку Notes.

## Проверка в Windows

Создайте две задачи и несколько чек-поинтов. Введите заметки в четыре вида строк, сохраните переходом фокуса, затем переименуйте задачу и чек-поинт двойным щелчком. Перетащите задачи и чек-поинты вверх и вниз; перезапустите приложение и проверьте порядок, имена, статусы и заметки. Выберите каждый тип песни, проверьте значки и сохранение после перезапуска. Убедитесь, что `.song` не изменился.
