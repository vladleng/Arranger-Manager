# Arranger Manager 0.1d — папки треков и Notes песни

Дополнение поверх 0.1c. Приложение читает сохранённый `.song` и не изменяет его.

- Папки дорожек Studio Pro показаны в дереве песни, включая вложенные. Папка появляется только тогда, когда внутри неё есть дорожка с распознанным статусом в имени. Дорожки без статуса и пустые для обзора папки скрыты. Папку можно свернуть, её цвет читается из проекта. PROG песни по-прежнему считает сами размеченные дорожки и локальные задачи, без добавления папок в знаменатель.
- Контекстные меню песни, папки каталога, задач, чек-поинтов и клипов открываются у места щелчка правой кнопкой. Меню Status и Type открываются у нажатой ячейки.
- В строке песни есть своя **локальная** Notes: щёлкните в ячейке и пишите, выход из поля сохраняет, Esc отменяет. Как и другие локальные заметки, она остаётся после перезапуска приложения. Notes из Studio Pro продолжают отображаться в шапке песни и не заменяются локальной записью.

## Проверка в Windows

Откройте сохранённый `.song` с папкой, внутри которой есть дорожка `WIP | ...` или `DONE | ...`, и с папкой только из дорожек без статуса. Проверьте порядок, вложенность, сворачивание и неизменность PROG. Щёлкните правой кнопкой по названию песни и задаче, а затем по Status/Type: меню должно появиться рядом с курсором. Запишите Notes в строке песни, перезапустите приложение и убедитесь, что запись осталась, а исходные Notes в шапке не изменились.
